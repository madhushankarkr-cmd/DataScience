# Diabetes Prediction System

This project predicts whether a person is likely to have diabetes based on medical data such as glucose level, BMI, age, and blood pressure. It uses machine learning algorithms to analyze the input data and generate predictions. The model is trained on a diabetes dataset to achieve accurate results. This project helps in the early detection of diabetes and supports healthcare decision-making. Technologies used include Python, Pandas, NumPy, and Scikit-learn.
